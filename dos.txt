
We are going to re-write the dos.js script, there are no functions using this existing code so nothing needs to be "backwards compatiable", everything in this script is a fresh start. Ignore previous versions of dos.js so there is no need to preserve ang legacy code. 

This script is for <host> disk operations that has global scope with access to file:/// and localStorage.  

The manifest should be renamed to "dir.txt" and only needs to keep track of filename and filesize.  
This file can exist on any "device", ie: file:/// and localStorage. The only file attributes this dir.txt file needs to keep track of is the filename, filesize, and timestamp.

Filename should include the extension (.js .txt .prg etc) to determine if it is executable. If the first letter of a filename is an explaination mark (!) it is considered "important" and therefore read-only. The ! is optional in the user input for filename, so !piano.prg is the same as piano.prg. To delete such a file, the user must first rename it to remove the write-protection.

Filesize should be number of bytes, the display routines can convert it to human-readable format. Timestamp should be yyyymmddhhmmss format (first mm month second mm minute). This would be an exmaple dir.txt file that could be included in the same directory as qandy-host.htm:
 
!qandy.js|30231|20260301021149
video.txt|210000|20260301021149
ascii.prg|12400|20260301021149
notes.txt|1234|20260301021149

I want to add "file" for file:/// to the list of supported devices, this should be the new default device so a user's first experience with the Qandy will be the pre-installed default scripts and programs that us developers include in the deployment (ie: piano.prg).   

This is the dos.txt file which contains the instructions for the user, please use the same variable names as in the instructions so the instructions are not just for the end user, but for future programmers as well. 

 

                 
                       Qandy PC DOS:
                       Disk Operating System


         DOS=true/false — set to true if DOS is enabled, all DOS functions should
                          be inside "if (DOS) {}" checks    

       dosMount(device) — sets the active device to access, default "file" for file:///
      
          DEVICE="name" — local var for active device
      
        dosBackup(data) — formats active device with JSON strong, if data is omitted
                          returns JSON string with contents of device for backup
     
              dosList() — returns string with list of filenames separated by new lines
              
              dosDir(h) — returns string with list of filenames, filesizes, and
                          timestamps. h is for "human readable", if set to 0 raw
                          filesizes and timestamps are used, but if set to 1 it
                          displays sizes as 1b 1k 1m (bytes, kilobytes, megabytes)
                          and timestamps are formated mm/dd/yyyy hh:mm:ss. The h=1
                          can be formated with space indents, ie:

                          video.txt 21k
                            03-01-2026 02:11:49
                          ascii.prg 12m
                            03-01-2026 02:11:49

                          and h=0 can be formated the same way:

                          video.txt 210000
                            20260301021149
                          ascii.prg 12400
                            20260301021149

          
                      
     dosSave(file,data) — saves var data as filename to active device, if filename
                          begins with > (">filename") append data to existing file,
                          do not allow append on filenames that start with ! in the
                          dir.txt for write-protect mode. Do not allow the dir.txt
                          file to be saved, it is write-protect by detault.

          dosLoad(file) — returns contents of filename from active device as string,
                          if file is dir.txt return contents of formated directory
                          via dosDir(1)
                          
    dosCopy(file, dest) — copies file into clipboard for dosPaste command, 
                          if dest is provided it also copies the file into
                          the dest file, returns error if dest already exists
                          
         dosPaste(dest) — pastes the clipboard contents into dest, will append
                          the data to existing dest if dest starts with ">" character,
                          otherwise returns error if file already exists.

  dosRename(file, dest) — renames file to dest 

          dosType(file) — print() file to display screen, if file is dir.txt
                          then print the results of dosDir(0)
            
        dosDelete(file) — deletes filename from active device 

        dosExists(file) — returns true if filename exists      



                   name — Name of file, maximum length 255 bytes, allowed
                          characters: A–Z, a–z, 0–9, space (leading/trailing
                          trimmed), minus, underscore, dot (but not first
                          character), parentheses, plus, and equals: -_.()+= 
                       
                   data — plain UTF‑8 text, use base64 for binary data, dos.js
               
                                     returns whole file content as a single text string.
                       
                 device — file, local, echo, or none.
