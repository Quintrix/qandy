The 'Qandy Pocket Computer' is an idea: the idea that the
user should own their operating system and not have to
license software that requires the user to agree to any
terms of service. The Qandy was written with AI, and as 
such it is a 'public domain' operating system that no
corporation can claim ownership of, not even a corporation
owned by its own programmers.

This repo is for the '1984 Qandy Pocket Computer' that uses
a JavaScript CPU to run in a web browser giving the user
access to video, keyboard, sound card, and it's multi-player
graphic engine APIs, where the user can write programs
on their cell phone without developer mode or USB debugging. 

Our flagship product with be a multi-player port of Richard
Carr's 1992 award winning shareware of the year 'Capture
the Flag', and a re-boot of the successful 1990's MMORPG
'Queville' franchise.

We seek to answer the question: what would the internet look
like if the Commodore 64 became the modern computer instead
of Windows 3.1?

Answer: Quantum Link. It is our intention to emulate a new
internet on qandy.net that will only host websites that have
JavaScript turned off - JavaScript is the computer's CPU
and we should not give untrusted outsiders access to the CPU,
which eliminates 90% of all malicious online activity including
random ware, crypto mining, and forces corporations to use
their own hardware to track users, not our own computers. 



Current Progress: The Qandy boots up, emulates a retro terminal
ANSI graphics, DOS-like commands, sound card, and a multi-player
graphics engine. When it is fully functional we will  starting a
new 'cylon.js' which will be to the Qandy what Windows was to
DOS. 

Through this Cylon OS anew '2029 Qandy' will be designed which
will run on a single board computer computer that fits into the
pocket and has a touch screen display, similar in design to a
cell phone but with usb ports, hdmi out, ethernet, bluetooth,
wifi, and sd card. It will have a full screen landscape virtual
keyboard with the ability to connect to a TV for display, or use
a physical keyboard via usb ... which turns the touch screen
display into a 'server status'. 

The IBM PC was successful because they used off the shelf parts
and anyone could make a clone: by designing the Qandy with
a touchscreen like a cellphone, nearly every cellphone owner
has the 1 part they need to build a Qandy. We call running the
Qandy on a cellphone with 'termux' an 'emulator', and it will
be designed so that other 'Qandys' can connect ... one cellphone
could be the display and another one can connect as the keyboard.

So the '2029 Qandy' is going to be more of a 'main frame' than
a personal computer. It will use a corporate-free Debian
linux to run a node.js server which will then run it's own
operating system inside a standard web browser, so while
'chrome os' tries to hide the operating system from the user,
the browser will be the Qandy's operating system.
